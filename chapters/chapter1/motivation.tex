\section{Motivation}

\subsection{Existing System}

Many schools and universities use automated systems to manage the steps of admitting new students. These systems vary in what they can do how well they. How they are set up depending on what each school needs and what resources they have.

\medskip

\noindent The current system used by JUST is called ``Admission 2025'' and it is available online. This system has some features but it does not cover everything needed.

\medskip

\noindent Some key features are missing like confirming admission sending messages to confirm admission and checking documents. Another problem with the system is that anyone can sign up no matter if they have been accepted or not. This leads to information and makes the system less reliable.

\medskip

\noindent The system also does not properly check the information that is submitted which can make it hard to ensure that the information is correct and real.

\subsection{Limitations of the System}

\noindent The current system has issues that affect how well it works and how easy it is to use. The major limitations are highlighted below:

\begin{itemize}
    \item One major issue is that there is no way to check if the information entered is correct. This means users can enter incomplete information without any restrictions.
    \item Another issue is that the system allows users to add data without limits but does not have ways to update or remove data. This can lead to data.
    \item The way the system is set up and the code it uses are not well organized. This makes it hard to fix grow or add features to the system in the future.
    \item Also people who have not been accepted can still sign up which reduces the accuracy and trustworthiness of the admission process.
    \item Key features like confirming admission sending automated messages and verifying documents are either missing or not fully working. This prevents the system from being a solution, for automating admissions.
\end{itemize}
