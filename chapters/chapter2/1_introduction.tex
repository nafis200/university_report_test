\section{Introduction}

\subsection{Purpose}

\noindent The main goal of the Undergraduate Final Admission System (JUST-UFAS) is to give a safe, fast and easy-to-use platform for finishing the final admission process.

\vspace{0.3cm}

\noindent The old manual and semi-automated system had problems.

\vspace{0.3cm}

\noindent These problems included no checks, bad code, no structured design and no way to enforce deadlines.

\vspace{0.3cm}

\noindent This system is the fully integrated solution made by the JUST Undergraduate Admission Committee.

\vspace{0.3cm}

\noindent It aims to fix existing problems by adding checks controlling deadlines and giving different access levels to users.

\vspace{0.3cm}

\noindent The system also has an more scalable design.

\vspace{0.3cm}

\noindent This Software Requirement Specification (SRS) document explains the workflow of the final admission process, which includes:

\begin{itemize}
    \item Applicants filling out forms.
    \item The Dean Office. Clearing applicants with required documents.
    \item The Hall Office verifying bank receipts.
    \item The Medical Center doing exams and reporting results.
    \item The Registrar Office giving approval and collecting documents.
    \item Administrative control for managing users, roles and system operations.
\end{itemize}
