\subsubsection{Update Applicant Information (Admin)}
Use Case: Update Applicant Information (Admin)
The update applicant information use case involves the ability of the Admin to change the details of the applicant in the system. The Admin can first log into the admin panel and search for a particular applicant in the applicant table. After searching for the desired applicant, the Admin will be able to edit the required fields. After editing the fields, the Admin can click on the update button to save the changes.
