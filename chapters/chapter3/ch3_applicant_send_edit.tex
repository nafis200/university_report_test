\subsubsection{Send Edit Request}
In the use case Send Edit Request, the applicant sends a request for authorization from the Admin to change information he or she has entered in the application form. Once a user completes the process of application form generation and gets access to the application form, he or she may send a request to change the data provided. This process is registered and approved by the admin. The use case often occurs when applicants make mistakes in the provided information.
