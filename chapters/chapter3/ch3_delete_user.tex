\subsubsection{Remove User Data}

This use case outlines the administrative action of deleting a user’s account from the \textit{Digital Admission Procedure Management for Post-GST Candidates}. This use case enables the Admin to ensure data integrity by eliminating unnecessary or duplicate accounts from the database.

    \centering
    \small
    \renewcommand{\arraystretch}{1.4}
    % ক্যাপশন এবং লেবেল উপরে সেট করা হয়েছে
    \caption{Use Case Table: Remove User Data (UC-1.4)}
    \label{tab:use_case_remove_user}
    
    \begin{tabularx}{\textwidth}{|l|X|}
        \hline
        \rowcolor[gray]{0.9} {Characteristics} & {Description} \\ \hline
        Use Case ID & UC-1.4 \\ \hline
        Use Case Name & Remove User Data \\ \hline
        Primary Actors & Admin \\ \hline
        Goal in Context & To permanently delete a specified user account from the system database. \\ \hline
        Precondition & The Admin must be logged into the system with administrative privileges. \\ \hline
        Post-condition & The specified user account will be successfully deleted from the PostgreSQL database through Prisma. \\ \hline
        Trigger & Admin notices that a certain account requires deletion for maintenance purposes. \\ \hline
        Scenario & 
        \begin{enumerate}[nosep, leftmargin=*]
            \item The Admin goes to the User Management page on the dashboard.
            \item The system retrieves the complete list of registered users in the database.
            \item The Admin identifies the particular user to be deleted.
            \item The Admin clicks on the Delete button for the selected user.
            \item The system displays a confirmation dialog box to avoid unintended deletion.
            \item After confirming the action, the backend performs the deletion using Prisma.
        \end{enumerate} \\ \hline
        Exception & {Deletion Failed:} If the user is linked to critical active records, the system prevents deletion and shows a "Constraint Error." \\ \hline
        Frequency of Use & Low to Medium (As needed for system cleanup). \\ \hline
    \end{tabularx}
\end{table}
