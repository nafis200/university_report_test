\subsubsection{Updating Information of Candidates}

This particular use case enables the Administration to make changes or corrections to the candidates’ information in the system. This ensures that all the data in the database is always updated and accurate. The users can easily edit information for the selected candidate by filling in the necessary information in the required fields. The changes are then submitted through the ‘Update’ button.
