\subsubsection{View All Applicant}
The View All Applicants use case is used by the registrar’s office to get information about all the registered applicants of the system. The user logs into the dashboard and uses this particular use case via the sidebar menu. The system provides all the details of applicants in a well-organized manner. It is very useful in checking the overall status of applications and carrying out admission process effectively.
