\subsubsection{Download Application Form}

This use case enables the applicant to create and download a PDF version of the submitted application. The use case serves as an official documentation for the applicant, which is vital during the physical verification procedure at the \textit{JUST}.

    \centering
    \small
    \renewcommand{\arraystretch}{1.4}

    \caption{Use Case Table: Download Application Form (UC-1.7)}
    \label{tab:use_case_download_form}
    
    \begin{tabularx}{\textwidth}{|l|X|}
        \hline
        \rowcolor[gray]{0.9} \textbf{Characteristics} & \textbf{Description} \\ \hline
        Use Case ID & UC-1.7 \\ \hline
        Use Case Name & Download Application Form \\ \hline
        Primary Actors & Applicant \\ \hline
        Goal in Context & To have a digital/physical copy of their admission application form as documentation. \\ \hline
        Precondition & The applicant should have logged in to the application and should have submitted his/her application form already. \\ \hline
        Post-condition & A PDF file will be generated and downloaded to the applicant’s device. \\ \hline
        Triggers & The applicant clicks the “Download PDF” or “Print Application” button in their dashboard. \\ \hline
        Scenario & 
        \begin{enumerate}[nosep, leftmargin=*]
            \item The applicant logs into their personal dashboard.
            \item The system checks the application status from the database using PostgreSQL.
            \item The applicant presses the button “Download PDF” on the dashboard.
            \item The server-side of the Next.js generates the application in PDF format based on the stored application data.
            \item The file download starts in the browser of the applicant.
            \item The applicant downloads the application form in PDF format.
        \end{enumerate} \\ \hline
        Exception & \textbf{Generation Error:} If the server fails or the database cannot be reached, the system displays a "PDF Generation Failed" error. \\ \hline
        Frequency of Use & High (Once per applicant after submission). \\ \hline
    \end{tabularx}
\end{table}
