\subsubsection{Download Application Form}
The Download Application Form use case enables the applicant to download the application form for admissions in pdf format. After logging into the system, the user will find this use case from the dashboard of the application. The system will produce the final application form and allow downloading of the same. This use case makes sure that the applicant will have easy access to his/her application form for further references.
