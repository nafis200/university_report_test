\subsubsection{Create New Record}
The Create New Record use case gives the opportunity for the Registrar to create and download customized records for their management processes. After signing into the system, the user will have access to this functionality through the side panel. The system allows choosing necessary fields and creating a structured record file based on them. After the process of configuration is finished, the created file will be available for downloading by a certain name.
