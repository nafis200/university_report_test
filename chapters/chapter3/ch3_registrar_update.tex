\subsubsection{Update Applicant Information}
The Update Applicant Information use case gives the Admin the ability to change and update the specified applicant's profile information. With appropriate authentication, after login, the Admin navigates to the applicant table. Changes can be done to the necessary fields for maintaining accuracy and updating of the records. When the modifications are done, the admin uses the update button to save changes made. This is usually useful in the process of verifying and updating the information.
