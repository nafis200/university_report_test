\subsubsection{Search Applicant}
This use case allows the Medical Office to search for an applicant using the system dashboard. It provides a quick way to locate applicant information through the search box. The system retrieves relevant details instantly after the search is performed. This feature helps save time and reduces manual effort. It also supports efficient handling of applicant records.
