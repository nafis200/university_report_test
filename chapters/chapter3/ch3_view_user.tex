\subsubsection{View User Information}

This use case enables the Admin to view the complete profile and access level information of all users (Applicants and Staff) in the \textit{Digital Admission Procedure Management for Post-GST Candidates}.

\begin{table}[H]
    \centering
    \small
    \renewcommand{\arraystretch}{1.5}
    \caption{Use Case Table: View User Information (UC-1.5)} % ক্যাপশন উপরে আনা হয়েছে
    \label{tab:use_case_view_user_info}
    \begin{tabularx}{\textwidth}{|l|X|}
        \hline
        \rowcolor[gray]{0.9} {Characteristics} & {Description} \\ \hline
        Use Case ID & UC-1.5 \\ \hline
        Use Case Name & View User Information \\ \hline
        Primary Actors & Admin \\ \hline
        Goal in Context & To display the complete profile details, account status, and role information of a particular user. \\ \hline
        Precondition & The Admin is required to be authenticated and logged into the administrative dashboard. \\ \hline
        Post-condition & The detailed information of a particular user is obtained from the database and shown on the screen. \\ \hline
        Trigger & The Admin has a need to verify the credentials of the user or investigate a particular account. \\ \hline
        Scenario & 
        \begin{enumerate}[nosep, leftmargin=*]
            \item The Admin accesses the User Management section or all users in the dashboard.
            \item The Admin searches for the desired user using their ID, Name, or Email using the search bar provided.
            \item The Admin selects the 'View Details' or 'Profile' button of the user.
            \item The Next.js application queries for that particular user’s information stored in the PostgreSQL database using Prisma.
            \item The user’s profile is rendered on the screen.
        \end{enumerate} \\ \hline
        Exception & {User Not Found:} If the requested user ID does not exist, the system displays a "Record Not Found" message. \\ \hline
        Frequency of Use & High (Used frequently for administrative oversight). \\ \hline
    \end{tabularx}
\end{table}
