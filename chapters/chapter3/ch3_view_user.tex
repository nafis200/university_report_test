\subsubsection{View User Information}

This use case allows the Admin to view detailed profiles and access levels of all users (Applicants and Staff) registered within the system. It is essential for verifying user identity, checking account status, and managing system-wide permissions in the \textit{JUST Undergraduate Final Admission System}.
