\subsubsection{Decline Applicant}

Use Case Description on How to Reject an Applicant if Discrepancies Exist in Documentation/Eligibility
The system permits the authorized person to go through the application that has been submitted by an individual before reaching the decision-making stage.
Any erroneous, incomplete, or invalid information discovered during the process can lead to the rejection of an applicant’s application.
It is important to ensure that there is a valid justification for rejecting an application. 
The applicant will receive notification from the system about the rejection of his/her application.
