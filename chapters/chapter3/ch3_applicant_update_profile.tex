\subsubsection{Update Profile}
The Update Profile Use Case allows the applicant to update their personal data to make sure the details provided in the application are current. When the user logs into the system they will be able to find their dashboard where they will find the option to go to the profile page. From there, the update form will allow the user to update the necessary details from within the system.
