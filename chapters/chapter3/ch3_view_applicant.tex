\subsubsection{View Applicant List}

This use case allows administrative staff to access and browse the list of applicants for admission. It provides Admin, Dean, Hall, Medical, and Registrar offices with the ability to filter and monitor applicants based on their category.

    \centering
    \small

    \label{tab:view_applicant_list}
    \begin{tabularx}{\textwidth}{|l|X|}
        \hline
        \rowcolor[gray]{0.9} \textbf{Characteristics} & \textbf{Description} \\ \hline
        Use Case ID & UC-1.2 \\ \hline
        Use Case Name & View Applicant List \\ \hline
        Primary Actors & Admin, Dean Office, Hall Office, Medical Office, Registrar Office \\ \hline
        Goal & To sort and display applicant records by filtering categories such as All, Admitted, or Waiting. \\ \hline
        Precondition & The user must be logged in with proper credentials to view applicant records. \\ \hline
        Post-condition & The selected applicant list is displayed on the user interface. \\ \hline
        Trigger & When there is a need to verify an applicant’s status or departmental clearance. \\ \hline
        Scenario & 
        \begin{enumerate}[nosep, leftmargin=*]
            \item The user logs in and opens the Dashboard.
            \item The user selects 'Applicant Management' or 'View List' from the sidebar menu.
            \item The user chooses a specific category (All Applicants, Admitted, or Waiting).
            \item The system retrieves the relevant data from the PostgreSQL database using Prisma.
            \item The applicant records are displayed in a structured table for review.
        \end{enumerate} \\ \hline
        Exception & \textbf{Access Denied:} If the user does not have permission to view the list, an "Unauthorized Access" message is shown. \\ \hline
        Frequency of Use & High (used frequently by administrative staff). \\ \hline
    \end{tabularx}
